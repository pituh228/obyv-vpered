# Паспорт проекта

> Шаблон для заполнения на паре 5. Примеры в скобках — из эталона ShoeShop.
> Файл живёт в репозитории: `docs/passport.md`

## 1. Название проекта  
Магазин обуви „Вперед“

## 2. Проблема

 Дорогая обувь у конкурентов. Некачественная обувь

## 3. Пользователи

Покупатель,ищет обувь по размеру, бренду и цене, оформляет заказ на примерку в магазине
Продавец-консультант, добавляет новые модели, отмечает продажи и поступления
Администратор, управляет учётными записями сотрудников и правами доступа.

## 4. Цель проекта

Дать покупателю возможность найти удобную ему обувь, которая будет не слишком дорогой.

## 5. Метрики успеха
Время оформления заказа:<3 минут
Клиент находит товар через поиск/фильтры за <5 кликов
Остатки обновляются автоматически после продажи, без ручного ввода


## 6. Границы (что НЕ делаем)
Не ведем бонусные карты
Не связываем с неизвестными поставщиками и складами
Не создаем мобильного приложения
Не штрафуем работников за украденный товар

## 7. Риски
Если мало товаров - заранее заказываем нужное колво
ДАнные теряются при сбое -делаем резервные копии базы данных
Если работники заболели- то делим обязанности между оставшимися работниками
